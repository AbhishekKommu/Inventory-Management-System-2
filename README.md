# 📦 Inventory Management System

A modern and responsive **Inventory Management System** designed to help businesses efficiently manage products, stock levels, suppliers, and inventory operations through a clean and user-friendly interface.

The application is built with **React, TypeScript, Vite, Tailwind CSS, and Supabase**, providing a fast and scalable foundation for inventory management.

---

## 🚀 Features

* 🔐 User Authentication
* 📦 Product & Inventory Management
* ➕ Add New Products
* ✏️ Update Product Information
* 🗑️ Delete Products
* 📊 Inventory Dashboard
* 🔎 Search & Filter Products
* 📈 Stock Monitoring
* ⚠️ Low Stock Tracking
* 🗄️ Database Integration
* 📱 Responsive Design
* 🎨 Modern & Professional UI
* ⚡ Fast Vite Development Environment
* 🔄 Real-Time Database Operations with Supabase

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/inventory-management-system.git
```

### 2. Navigate to the Project

```bash
cd inventory-management-system
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the project root and add your Supabase configuration:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 5. Start the Development Server

```bash
npm run dev
```

### 6. Open in Browser

```text
http://localhost:5173/
```
